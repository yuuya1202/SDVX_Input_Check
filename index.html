SDVX INPUT CHECK
SDVX専用の入力可視化ツール
SDVX INPUT CHECK

⚠ キーボードや一部のコントローラーをご利用の場合は特定の機能に支障が出る場合があります。詳しくは下の「注意事項」を参照ください。

概要

このツールは、SDVXコントローラー（またはキーボード代用）の入力をリアルタイムに可視化する練習ツールです。実際のプレー画面のような見た目でBT/FX/VOLの入力タイミングを確認したり、自作の簡易譜面に合わせて精度を練習したり、プレイを録画して見返したりできます。

まず最初にやること：マッピング

1.「マッピング」タブを開きます。
2. コントローラーを使う場合は「コントローラー」サブタブ、キーボードでテストしたい場合は「キーボード」サブタブを選択します。（コントローラーでキーボードモードを選択している場合は「キーボード」サブタブを使用してください）
3. 各内容の割り当てを行ってください。

マッピングやオプションの設定は自動的にブラウザに保存されるので、次回開いたときも引き継がれます。コントローラーは複数接続していても、ヘッダーのプルダウンから使うものを選べます。

「プレイ」タブ

マッピングした入力がリアルタイムに流れてくるビジュアライザー画面です。右上の「オプション」パネルで、スクロール速度・ロング判定閾値・VOL-L/Rの色を調整できます。「● 録画」ボタンでプレイを録画でき（最大3分）、録画したものは「録画再生」タブで確認できます。

「譜面練習」タブ

譜面作成：1/4小節を1ブロックとして、ブロックごとに好きな分割数でノーツを配置し、自分だけの練習パターンを作れます。「コピー」「貼り付け」で繰り返し部分を複製可能です。完成したら「練習する」を選択してください。

練習：作った譜面がノーツとして流れてくるので、実際にプレイして精度を確認できます。BPM・スクロール速度・判定ライン位置を調整可能です。プレイ終了後、「再生する」で直前のプレイを見返すか、「戻る」でもう一度プレイできます。

「録画再生」タブ

「プレイ」タブや「譜面練習」タブで録画したプレイを見返せます。シークバーで好きな位置に移動でき、再生速度（x0.1〜x1.0）やスクロール速度も調整可能です。キー音のON/OFFもここで設定できます。

使用例

・譜面練習機能で反復練習：自作した簡易パターンを何度も繰り返し流し、BT/FXの精度を高める
・プレイの録画・見返し：実際のプレイを録画しておき、押し遅れや取りこぼしのタイミングを後から確認する
・OBS配信での画面キャプチャ：配信・録画ソフトで実際のゲーム画面と並べてキャプチャし、視聴者に自分の入力状況を見せながら配信する

⚠ 注意事項

コナステ・K-Shoot MANIAとの併用について
キーボード入力、またはボタン操作がキーボード入力として処理される機器は、コナステやK-Shoot MANIAとの相性が悪く、併用できません。ブラウザ／OSの仕様上、キーボード入力は操作中（フォーカスがある）のウィンドウにしか送られないため、コナステやK-Shoot MANIAを操作している間は、本ツールはキーボード入力を検知できなくなります。本ツールを単体で使用する場合は問題ありません。

譜面作成

左のパレットで「BT」「FX」「BTロング」「FXロング」のいずれかを選ぶと配置モードになります。その状態でレーン上の任意の場所をクリックするとノーツが置けます（ロングは配置時は最小サイズで置かれます。長さを調整する場合はノーツをクリックし、上辺・下辺をドラッグして長さを調整できます）。

配置済みのノーツはクリックすると選択状態となります。選択状態のノーツはドラッグすることで移動、Backspaceキーで削除できます。

分割数・コピー・貼り付けは各ブロックの左側で操作してください。
